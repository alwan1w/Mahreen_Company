## 🚀 Overview

**Inisiatif Pemuda 2026** is a modern web development project that focuses on providing an immersive and responsive user experience. This platform serves as a hub for youth to innovate, collaborate, and create meaningful social impact through digital solutions.

## 🛠 Tech Stack

Built with a modern stack to ensure high performance and aesthetic appeal:

* **Framework:** [React.js](https://react.dev/)
* **Build Tool:** [Vite](https://vitejs.dev/)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Animation:** [Framer Motion](https://www.framer.com/motion/)
* **Smooth Scroll:** [Lenis](https://github.com/darkroomengineering/lenis)

## ✨ Key Features

* **Dark-Mode First Design:** A futuristic and minimal aesthetic perfect for modern tech applications.
* **Immersive Animations:** Fluid entry animations and scroll-triggered effects powered by Framer Motion.
* **Responsive Bento Grid:** A highly organized, card-based layout that adapts seamlessly to any screen size.
* **Custom Interactivity:** Includes custom cursors and dynamic elements to make browsing feel premium.
* **Smooth Navigation:** Utilizes Lenis for a silky-smooth scrolling experience.

Make sure you have [Node.js](https://nodejs.org/) installed on your machine.


